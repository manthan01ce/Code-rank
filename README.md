# CodeRank

CodeRank is a programming practice and practical assessment platform. The repository contains a Next.js web app, a Fastify HTTP and Socket.IO API, and a grading worker.

- [Getting started](docs/getting-started.md) covers setup, launch commands, and preserving existing database and Redis volumes.
- [Three-app topology](docs/architecture/three-app-topology.md) explains service ownership.
- [Deployment and operations](docs/deployment/DEPLOYMENT_OPERATIONS.md) covers the release workflow.
- [Testing](docs/development/test-inventory.md) and [load qualification](load-tests/QUALIFICATION.md) describe verification.
- [Historical guides and evidence](docs/archive/2026-11/README.md) preserve earlier snapshots.

See [repository ownership](docs/development/repository-layout.md) for the layout and command owners.
